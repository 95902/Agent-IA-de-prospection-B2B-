## Objectif
Clore le MVP (9 semaines) en comparant les résultats réels aux cibles définies dans le PRD, et préparer la Phase 2.

## Métriques à comparer vs cibles PRD (section 6)
- [ ] Prospects collectés/semaine (cible ≥ 500)
- [ ] Taux enrichissement téléphone (cible ≥ 40%) / email (cible ≥ 20%)
- [ ] % prospects qualifiés (cible ≥ 30%) et score moyen des qualifiés (cible ≥ 65/100)
- [ ] Accord humain/score IA (cible ≥ 75%, voir #32)
- [ ] Coût par prospect qualifié (cible ≤ 0.15€)
- [ ] Durée pipeline 500 prospects (cible ≤ 45 min)
- [ ] Taux appels → RDV (cible ≥ 2%)

## Décisions Phase 2 à trancher (voir PRD, roadmap)
- [ ] Agent vocal automatisé (Retell AI) — priorité et calendrier
- [ ] Pipeline mailing automatique (Brevo)
- [ ] Interface web self-service pour la configuration ICP (actuellement configuration en base via script/admin)
- [ ] Retour d'expérience sur le premier client pilote : le barème générique de scoring était-il adapté à son secteur, ou faut-il ajuster l'approche pour les prochains clients ?

## Critères d'acceptance
- [ ] Un document de rétrospective compare chaque métrique cible vs réel
- [ ] Les décisions Phase 2 sont actées avec un propriétaire et un horizon indicatif
